# BarberSys - Sistema para barbearia

Tecnlogias:
 - Front - HTML,CSS e JavaScript
 - BackEnd - Python com Flask
 - Banco de dados : MariaDB

 O intuito do projeto é criar um sistema completo para barbearia, desde o cadastro dos clientes, barbeiros e serviços até agendamento online

Para rodar a aplicação, é necessario instalar o banco de dados MariaDB e configura-lo
